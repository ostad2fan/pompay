# تغییرات نسخه ۱.۴.۱۲ — ترکیب کامل دو مسیر + ۷ درخواست نهایی

این نسخه روی **کد پایدار ۱.۴.۱۱ گیتهاب** ساخته شده است (آخرین نسخه‌ای که بدون کرش اجرا می‌شود) و همه رفع‌های ۱.۴.۹ تا ۱.۴.۱۱ داخل آن است:
رفع کرش استارتاپ (`+native-intent` به‌جای `router.replace`)، باز شدن برنامه روی تنظیمات، رفع ناوبری‌های جزئیات نهنگ/میم/ترید AI، هماهنگی ساعت با سرور صرافی‌ها، بیتگت ۴۰۰۸۵ (حساب یکپارچه)، پیام‌های دقیق XT (AUTH_101 تا AUTH_106)، دانلود نسخه‌دار داخل برنامه، پله‌ای شدن درخواست‌ها و تلاش مجدد خودکار.

## ۱) چک IP هر ۲ ثانیه (قبلاً ۱۵ ثانیه)

- `VpnGateContext` حالا هر **۲ ثانیه** IP خروجی را چک می‌کند (قبلاً ۱۵ ثانیه).
- برای تحمل این سرعت: ارائه‌دهنده‌های geo-IP **به‌نوبت** می‌چرخند (بار بین ۳ سرویس پخش می‌شود)، تایم‌اوت هر چک به ۲.۵ ثانیه کاهش یافت، درخواست‌های همزمان **یک** درخواست مشترک می‌شوند (بدون انباشته شدن)، و کش داخلی ۳ ثانیه است.
- نتیجه: اگر فیلترشکن خاموش شود یا IP عوض شود و ایران تشخیص داده شود، صفحه قفل «فیلترشکن خاموش شد» حداکثر ~۲ ثانیه بعد ظاهر می‌شود و اتصال API همه بخش‌ها همان لحظه قطع می‌شود.

## ۲) تشخیص IP تحریمی برای هر صرافی (مهم‌ترین بخش)

- ماژول جدید `utils/geoBlock.ts`: هر پاسخ HTTP با وضعیت **۴۵۱ / ۴۰۳ / ۴۱۸** از هر صرافی ثبت می‌شود (۴۵۱ = Unavailable For Legal Reasons، یعنی بلاک جغرافیایی).
- تفاوت با گیت ایران: گیت ایران وقتی است که IP گوشی مستقیم ایران باشد (همه صرافی‌ها قطع). تحریم وقتی است که **فیلترشکن روشن است** ولی این **یک** صرافی کشور/IP خروجی شما را نمی‌پذیرد.
- وقتی تشخیص داده شود: دیالوگ «صرافی X تحریم است» می‌آید با توضیح «بقیه صرافی‌ها اوکی هستند» و دو دکمه: **«قطع این صرافی»** (فقط همان صرافی حذف می‌شود، بقیه متصل می‌مانند) و «باشه، بعداً».
- کارت قرمز دائمی هم روی همان صرافی می‌ماند: «صرافی X این IP را تحریم کرده» + دکمه‌های «قطع این صرافی» و «بررسی مجدد IP» — توضیح می‌دهد با IP غیرتحریمی (کشور دیگر) دوباره تلاش کنید.
- هم روی موجودی و هم روی سود/زیان دوره‌ای همان صرافی اعمال می‌شود (پیام دقیق جای متن عمومی «خطا در دریافت» می‌آید).

## ۳) سود/زیان (PnL) بیتگت روی همه تایم‌فریم‌ها

- ریشه «خالی در همه تایم‌فریم‌ها» پیدا شد: حساب‌های یکپارچه (UTA) بعضی وقت‌ها به مسیر قدیمی v2 پاسخ `00000` با **لیست خالی** می‌دهند (به‌جای خطای 40085) → برنامه صفر می‌خواند و مسیر UTA هرگز امتحان نمی‌شد.
- حالا: نتیجه خالی از مسیر v2 → مسیر **UTA v3** (`/api/v3/position/history-position`) هم خودکار امتحان می‌شود و اگر ردیف داشت همان عدد استفاده می‌شود.
- مسیر UTA مقاوم‌تر شد: هر دو املای category (`USDT-FUTURES` و `linear`)، هر سه شکل ردیف‌ها (`list` / `rows` / `positionList`)، فیلد‌های زمانی متنوع (`updatedTime`/`uTime`/`closeTime`/`createdTime`) و هر دو شکل صفحه‌بندی (`cursor`/`endId`).
- مسیرهای v2 و v3 و طرح امضا با کلید آزمایشی زنده تأیید شدند (پاسخ 40037 یعنی مسیر و امضا درست‌اند).

## ۴) موجودی XT با امضای v4

- اسپات: `sapi.xt.com/v4/balance` با هدرهای `xt-validate-*` و امضای HmacSHA256 — پارس نتیجه مقاوم (`result` آرایه یا `list`/`balances`/`data`).
- فیوچرز: `fapi.xt.com/future/user/v1/balance/list` — ردیف‌ها با `marginCoin`.
- اگر ساعت گوشی ناخوانا باشد (AUTH_105) دوباره با ساعت تازه‌شده تلاش می‌شود.
- خطاهای AUTH_101 تا AUTH_106 با راهنمای دقیق فارسی نمایش داده می‌شوند.

## ۵) تنظیمات به‌عنوان تب پیش‌فرض

- از ۱.۴.۱۱ بدون کرش برقرار است (`+native-intent` مسیر اولیه `/` را به `/settings` هدایت می‌کند + `initialRouteName="settings"`).

## ۶) اعلان‌های خاموش دیگر ارسال نمی‌شوند

- تلگرام هوک ریورسال حالا تابع تنظیم «اعلان هوک» است: وقتی خاموش شده، سیگنال‌ها تشخیص و ذخیره می‌شوند (تب هوک کار می‌کند) اما **هیچ پیامی به تلگرام نمی‌رود** — قبلاً صف سیگنال‌های زمان بسته بودن اپ موقع باز شدن همه با هم شلیک می‌شد.
- اندیکاتورهای دستی از قبل فقط اندیکاتورهای فعال (`receiveSignals`) اسکن می‌شوند — اندیکاتور خاموش = بدون اعلان.

## ۷) دانلود همیشه نسخه درست

- از ۱.۴.۱۰/۱۱ برقرار است: نام فایل نسخه‌دار (`PampDumpCoins-v1.4.12.apk`) + کش‌شکن روی version.json و خود فایل APK.
