# تغییرات نسخه ۱.۴.۱۶ (PampDumpCoins)

## ۱) تب چهارم جدید: «کیف پول بلاکچین (فقط خواندنی)»
در صفحه مدیریت دارایی، کنار سه تب قبلی، **تب چهارم «کیف پول بلاکچین»** اضافه شد.

**افزودن کیف پول + راهنمای فقط‌خواندنی (داخل خود فرم):**
- نام دلخواه + انتخاب شبکه + **آدرس عمومی** — همین و بس؛ بدون کلید خصوصی، بدون عبارت بازیابی
- زیر فرم، **راهنمای ۴ مرحله‌ای** گرفتن آدرس فقط‌خواندنی از خود تراست ولتم:
  باز کردن کیف → لمس آدرس بالای صفحه برای کپی (یا ⋯ ← View on Block Explorer) → برای هر شبکه از دکمه «دریافت» آدرس همان شبکه را کپی → Paste در فرم
- **هشدار امنیتی قرمز** زیر راهنما: هرگز عبارت بازیابی ۱۲ کلمه‌ای / کلید خصوصی را در هیچ برنامه‌ای وارد نکنید؛ این برنامه فقط آدرس عمومی می‌گیرد و هیچ‌کس (از جمله این برنامه) نمی‌تواند از کیف برداشت کند
- اعتبارسنجی زنده آدرس (شروع صحیح + طول + **چک‌سام ترون** با الگوریتم base58check)
- چند کیف پول، هر کدام جدا قابل افزودن/حذف/تازه‌سازی

**شبکه‌های پشتیبانی‌شده — همه بدون هیچ کلید API:**
| شبکه | روش خواندن موجودی |
|---|---|
| اتریوم | کشف کامل همه توکن‌های ERC-20 + قیمت (Blockscout عمومی) + مسیر جایگزین RPC |
| BNB Chain | RPC عمومی + توکن‌های تأییدشده (USDT/USDC/CAKE/ETH/BTCB) |
| پالیگان • آربیتروم • بیس | Blockscout عمومی (کشف کامل) + RPC جایگزین |
| ترون | TRX + تتر TRC-20 و USDC (TronGrid عمومی — قراردادها روی زنجیره تأیید شدند) |
| بیت‌کوین | mempool.space + blockstream.info |
| سولانا | RPC عمومی + کشف کامل توکن‌های SPL + قیمت Jupiter |

**نمایش دارایی‌ها:**
- کارت هر کیف: نام + شبکه + آدرس کوتاه + ارزش دلاری و تومانی + ردیف هر توکن (مقدار، ارزش دلاری، تغییر ۲۴ ساعته) + باز/بسته با فلش
- قیمت‌ها: بایننس (پرچم‌دار) + استیبل‌ها = ۱ دلار + Jupiter برای سولانا

**PnL کلی در همه تایم‌فریم‌ها (مثل بقیه بخش‌ها):**
- کارت «سود / زیان کیف پول‌ها» داخل کارت مجموع: چیپ‌های **۷ / ۳۰ / ۹۰ / ۱۸۰ روز**
- مبنا: موجودی امروز × تاریخچه قیمت پایان روز بایننس (Klines روزانه)
- نمایش کل + درصد + **معادل تومانی سود/زیان** + تفکیک هر توکن

**ارزش تومانی:**
- کارت مجموع: «ارزش دلاری» + «ارزش تومانی» (× قیمت تتر برنامه) + ردیف قیمت تتر

**نکات فنی:**
- اسنپ‌شات موجودی در AsyncStorage (نمایش آنی هنگام ورود، تازه‌سازی بی‌صدا بعدش) — دقیقاً الگوی صرافی‌ها
- گیت فیلترشکن مثل صرافی‌های خارجی: با IP ایران درخواستی ارسال نمی‌شود؛ با وصل شدن فیلترشکن همه چیز خودکار تازه می‌شود
- توکن‌های هرز (زیر ۱ سنت) و ردیف‌های بی‌ارزش حذف می‌شوند

## ۲) تب «دارایی ریالی و فلزات» — محاسبه کیف بلاکچین + چیدمان جدید
- **ردیف «کیف پول بلاکچین (فقط خواندنی)»** در «دارایی‌های من» با معادل تومانی (× قیمت تتر)
- موجودی کیف بلاکچین در **«مجموع کل»** محاسبه می‌شود: «ریال + دلار + طلا + نقره + سکه + ارز + کیف بلاکچین»
- **ردیف جدا «کیف پول بلاکچین»** در کارت «سود / زیان دارایی‌ها»: سود/زیان تومانی بر اساس تغییر قیمت بایننس × نرخ تتر/دلار در همان بازه
- **چیدمان جدید (طبق درخواست):** قیمت‌های لحظه‌ای ← **مجموع کل (بالای صفحه، همیشه نمایان)** ← کارت سود/زیان ← **«دارایی‌های من»** که حالا **با فلش باز و بسته می‌شود** (وضعیت باز/بسته ذخیره می‌شود)
- بقیه بخش‌ها (طلا/نقره/سکه/دلار کاغذی، تب ارز دیجیتال، تب پیش‌بینی طلا) بدون تغییر
