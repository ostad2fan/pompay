# تغییرات نسخه ۱.۴.۱۵ (PampDumpCoins)

نسخه ۱.۴.۱۵ یک آپدیت کوچک روی ۱.۴.۱۴ است که دو درخواست شما را اعمال می‌کند.

## ۱) جابجایی کارت سود/زیان (PnL) به بالای سربرگ
کارت «سود / زیان دارایی‌ها» که در ۱.۴.۱۴ بعد از «مجموع کل» (پایین‌ترین نقطه تب) بود، حالا:

- **درست زیر قیمت‌های لحظه‌ای** قرار گرفته (اولین کارت بعد از جدول قیمت‌ها)
- **همیشه نمایان است** — حتی وقتی بخش «دارایی‌های من» جمع (collapse) شده باشد
- بقیه رفتارش مثل قبل: بازه‌های ۷ / ۳۰ / ۹۰ / ۱۸۰ روز، تفکیک هر دارایی، مبنا از تاریخچه پایان روز TGJU

## ۲) ردیف جدید «دلار کاغذی (فیزیکی)»
در بخش «دارایی‌های من» بعد از «ریال / تومان نقدی»:

- مقدار دلار فیزیکی‌تان را وارد کنید (مثلاً 500)
- ارزش تومانی آن با **نرخ دلار آزاد بازار** (TGJU) محاسبه می‌شود
- اگر نرخ دلار آزاد در دسترس نباشد، از **نرخ تتر** استفاده می‌شود (کنارش نوشته می‌شود)
- دلار کاغذی در **مجموع کل** و تفکیک آن لحاظ شده: «ریال + دلار + طلا + نقره + سکه + ارز»
- سود/زیان دلار کاغذی هم در کارت PnL با تاریخچه نرخ دلار TGJU محاسبه می‌شود
- چیپ قیمت «دلار آزاد» به جدول قیمت‌های لحظه‌ای اضافه شد

