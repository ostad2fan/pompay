# تغییرات نسخه ۱.۴.۸ — IP در تنظیمات + قطع فوری + رفع کامل PnL

روی همان کد پایدار ۱.۴.۷ (که در گیت‌هاب شما آپلود شده) ساخته شده است.

## ۱) نمایش IP و کشور در تنظیمات (ابتدای لیست)

کارت جدید «وضعیت اتصال (IP)» در **اول لیست تنظیمات**:
- IP فعلی + کشور (نام فارسی وقتی موجود است)
- نشان وضعیت: سبز = فیلترشکن روشن / نارنجی = IP ایران / خاکستری = تشخیص موقتاً ناموفق
- دکمه تازه‌سازی + «آخرین بررسی»
- زنده: همان state مشترک ۱۵ ثانیه‌ای که کل برنامه استفاده می‌کند

## ۲) قطع فوری همه APIها وقتی وسط کار فیلترشکن خاموش شود

- یک **پولر مشترک** (`contexts/VpnGateContext`) IP خروجی را هر **۱۵ ثانیه** (و بلافاصله با هر بازگشت برنامه از پس‌زمینه) چک می‌کند.
- اگر IP ایران تشخیص داده شود (چه اول ورود، چه وسط کار):
  - **صفحه قفل تمام‌صفحه** «فیلترشکن خاموش شد / IP تغییر کرد» با پیام «اتصال همه بخش‌های برنامه قطع شد» + دکمه «فیلترشکن را وصل کردم — بررسی مجدد» + «تأیید و خروج»
  - **اسکنر اصلی** (دکمه اسکن و اسکن خودکار): درخواست اصلاً ارسال نمی‌شود و خطای واضح فارسی می‌دهد
  - **اسکنر میم‌کوین** (پول ۱۰ ثانیه‌ای) و **قبل از لیست** (پول ۳ ثانیه‌ای): کوئری‌ها غیرفعال می‌شوند
  - **کیف پول صرافی‌های خارجی**: از ۱.۴.۷ کاملاً گیت سخت دارد (همان‌جا)
- با وصل شدن فیلترشکن و «بررسی مجدد»، همه بخش‌ها خودکار ادامه می‌یابند و موجودی‌ها تازه می‌شوند.

## ۳) رفع PnL دوره‌ای بایننس (خالی نشان می‌داد)

**علت:** تابع PnL بایننس فقط endpoint درآمد **فیوچرز** را می‌خواند — حساب فقط-اسپات همیشه خالی/صفر برمی‌گشت.

**رفع:** سود/زیان **اسپات** داخل بازه هم محاسبه می‌شود:
- تاریخچه معاملات (USDT و FDUSD) هر ارز موجود در حساب، از ابتدای بازه
- هر **فروش** داخل بازه در برابر میانگین خرید لحظه‌ای ارزش می‌شود → سود/زیان محقق‌شده اسپات
- کارمزدهای USDT معاملات اسپات هم جمع می‌شود
- تعداد معامله‌های بسته = پوزیشن‌های فیوچرز + فروش‌های اسپات

## ۴) درصد سود/زیان همه ارزهای بایننس

سه ریشه پیدا و رفع شد که چرا بعضی ارزها PnL% نداشتند:
1. **تاریخچه فقط ۱۰۰۰ معامله آخر** بود → ارزهای با تاریخچه بلند، میانگین خرید غلط/تهی می‌گرفتند. حالا صفحه‌بندی با fromId تا ۵۰۰۰ معامله.
2. **فقط جفت USDT** خوانده می‌شد → خریدهای FDUSD دیده نمی‌شد. حالا USDT بعد FDUSD.
3. **ارزهای بدون جفت USDT** (لیست‌شده فقط با BTC/BNB) اصلا قیمت نداشتند → نه ارزش نه PnL. حالا قیمت از مسیر `ASSETBTC×BTCUSDT` یا `ASSETBNB×BNBUSDT` محاسبه می‌شود. سقف دارایی‌ها هم ۲۵ → ۴۰ شد.

## ۵) مکسی و بیتگت به PnL دوره‌ای اضافه شدند

- **مکسی:** `GET /api/v1/private/position/list/history_positions` (پوزیشن‌های بسته فیوچرز: `realised` + `holdFee`) — امضای ApiKey/Request-Time/Signature (تست زنده: مسیر و امضا پذیرفته شد)
- **بیتگت:** `GET /api/v2/mix/position/history-position` (همان امضای ACCESS-* کیف پول) — تست زنده انجام شد
- مجموع کل دارایی‌ها حالا **بایننس + بای‌بیت + OKX + مکسی + بیتگت + بیت‌پرپ** را جمع می‌زند و پیامش دقیق می‌گوید کدام صرافی‌ها در مجموع هستند.
- صرافی‌هایی که API این داده را ندارند (کوکوین/گیت/هوبی/...) همان پیام راهنمای قبلی را می‌دهند.

## ۶) موجودی ۵ سنت بیت‌پرپ

- آستانه مخفی‌کردن ارزهای کوچک ($1) برای **بیت‌پرپ حذف شد** — همه موجودی‌ها حتی چند سنت نمایش داده می‌شوند.
- اگر کل دارایی یک صرافی زیر $1 باشد، آن صرافی هم همه ردیف‌هایش را نشان می‌دهد (قبلا کارت خالی به‌نظر می‌رسید).
