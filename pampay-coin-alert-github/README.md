# ارزهای پامپی و دامپی (Pump & Dump Coins)

اپ React Native (Expo SDK 54) + سرور اسکنر Node.js — تشخیص سیگنال پامپ/دامپ، شورت میم‌کوین، قبل لیست، نهنگ‌ها، ترید AI و اندیکاتورها با اعلان تلگرام و پوش بومی حتی وقتی برنامه کاملاً بسته است.

## 🆕 تغییرات نسخه 1.4.4
- ⚠️ **هشدار امنیتی فیلترشکن**: اگر فیلترشکن خاموش باشد و صرافی خارجی متصل کنید، بنر «فیلترشکن روشن کنید» بالای صفحه مدیریت دارایی نمایش داده می‌شود (بررسی خودکار هر ۶۰ ثانیه — برای حفظ امنیت حساب‌های صرافی خارجی)
- 🗂 **مدیریت دارایی — ساختار جدید**: نوار سربرگ بالای صفحه حذف شد؛ هر صرافی یک کارت است که با فلش باز می‌شود و داخلش سربرگ‌های «همه + اسپات + ارن + آلفا + فیوچرز + فاندینگ» دارد؛ سربرگ «همه» دارایی تکراری در چند بخش را یکجا جمع می‌زند (مثلاً ارز در اسپات + ارن → مجموع)
- 🔑 **ورود بیت‌پرپ رفع شد**: به‌محض تایپ کد ۶ رقمی ورود خودکار انجام می‌شود + چند مسیر API + پیام خطای دقیق (اگر فیلترشکن لازم باشد می‌گوید)
- 🔔 **رفع «ثبت پوش ناموفق»**: فایل فایربیس داخل بیلد قرار گرفت + دکمه ثبت پوش حالا دلیل دقیق خطا را نشان می‌دهد (سرورهای گوگل از IP ایران در دسترس نیستند — با فیلترشکن ثبت کنید)
- 🧪 **دکمه جدید «تست ارسال تلگرام از سرور»** در تنظیمات — می‌گوید مسیر اعلان ۲۴ ساعته سالم است یا مشکل از توکن/چت‌آیدی است
- 📊 PnL دوره‌ای ۳۰/۹۰/۱۸۰/۳۶۰ روز دقیقاً از خود صرافی (بایننس/بای‌بیت/OKX/بیت‌پرپ) + مجموع کل دارایی هر صرافی
- 🔐 **کلید امضای نسل ۴** در همین مخزن ذخیره شد (`apk/keystore/`) — دیگر گم نمی‌شود؛ ولی برای نصب ۱.۴.۴ یک بار برنامه قبلی را حذف کنید (از این به بعد همیشه بدون حذف)

جزئیات کامل: `CHANGES-1.4.4.md`

## اتصال اپ به سرور
- آدرس پیش‌فرض `https://pompay-production.up.railway.app` **از قبل داخل برنامه قرار داده شده** و در تنظیمات ← «سرور اسکنر» خودکار پر شده است.
- اگر نسخه شخصی خودتان را دیپلوی کردید، همان فیلد را با آدرس خودتان ویرایش کنید ← تست و ذخیره ← همگام‌سازی پیکربندی.

## ⚠️ دیپلوی سرور روی Railway (مهم — ساختار درست)
سورس سرور در این مخزن داخل `pampay-coin-alert-github/server` است:

1. Railway → پروژه خودتان → service مربوط به این برنامه
2. **Settings → Root Directory = `pampay-coin-alert-github/server`** (نه `server` خالی — با مقدار اشتباه دیپلوی جدید شکست می‌خورد و Railway نسخه قدیمی را اجرا می‌کند!)
3. Settings → Deployments → **Auto Deploy** روشن باشد؛ بعد از هر تغییر در ریپو خودکار دیپلوی می‌شود
4. اگر Service از ریپوی گیت‌هاب جدا وصل شده، کافی است push/آپلود کنید؛ وگرنه دستی: تب Deployments → **Redeploy**
5. تست موفقیت: `https://<آدرس-سرور>/bot/test` باید JSON برگرداند (نه 404) و `/scan/status` باید `serverBotCommands: true` داشته باشد

بعد از دیپلوی جدید، **دستورات ربات تلگرام حتی با برنامه بسته ۲۴ ساعته پاسخ می‌گیرند** و مسیر اعلان‌های تلگرام فعال می‌شود.

## بیلد APK (محلی)
```bash
bash scripts/build-apk-local.sh   # همه‌چیز خودکار: prebuild + وصله‌ها + gradle
```
پیش‌نیازها: Node 20+، JDK 17+، `ANDROID_HOME` (platform-tools + platforms;android-36 + build-tools;36.0.0).
امضای release از `apk/keystore/pampay-release-key.jks` خوانده می‌شود (رمز: `PomPay2026Release`، alias: `pampay`) — **این فایل را حذف نکنید؛ همه نسخه‌های آینده باید با همین امضا ساخته شوند تا بدون حذف نصب شوند.**

## اعلان با برنامه بسته
- **کانال اصلی: ربات تلگرام** — سرور هر ۱۰ دقیقه/۱ ساعت/۴ ساعت/روزانه اسکن می‌کند و سیگنال‌های جدید را می‌فرستد (کاملاً مستقل از گوشی؛ حتی اگر گوشی خاموش باشد)
- **کانال دوم: پوش اندروید (FCM)** — فایل `google-services.json` از نسخه ۱.۴.۴ داخل بیلد است؛ در تنظیمات ← «ثبت نوتیفیکیشن گوشی» (برای موفقیت، فیلترشکن روشن باشد چون سرورهای گوگل از IP ایران در دسترس نیستند)
- عیب‌یابی: تنظیمات ← «تست ارسال تلگرام از سرور» ← اگر خطا داد، متن خطای خود تلگرام را نشان می‌دهد

## 🔁 انتشار نسخه جدید
1. فایل‌های این پوشه را در گیت‌هاب آپلود کنید (جایگزین قبلی‌ها)
2. APK جدید را جای `apk/PampDumpCoins-latest.apk` بگذارید و `apk/version.json` را با نسخه جدید آپدیت کنید
3. Railway خودکار دوباره دیپلوی می‌شود (اگر Auto Deploy روشن باشد)
4. برنامه‌های نصب‌شده، خودشان بنر «نسخه جدید» را نشان می‌دهند (بررسی از ۳ مسیر: سرور برنامه + CDN jsDelivr + گیت‌هاب)

## ساختار
- `app/` — صفحات اکسپو (اسکنر، میم، قبل لیست، نهنگ، ترید AI، مدیریت دارایی، اندیکاتورها، تنظیمات)
- `utils/` — سرویس‌ها (تلگرام، بایننس، نوبیتکس، بیت‌پرپ، GainzAlgo، هوک، پوش، VPN، AI)
- `server/` — سرور اسکنر Railway (پاسخ ۲۴ ساعته دستورات ربات + اسکن + اعلان)
- `scripts/` — بیلد محلی APK + وصله‌های gradle
- `apk/` — APK نهایی + version.json + کلید امضا
- `google-services.json` — فایربیس (پوش اندروید)
