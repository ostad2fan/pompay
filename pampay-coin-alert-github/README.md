# ارزهای پامپی و دامپی (Pump & Dump Coins)

اپ React Native (Expo SDK 54) + سرور اسکنر Node.js — تشخیص سیگنال پامپ/دامپ، شورت میم‌کوین، قبل لیست، نهنگ‌ها، ترید AI و اندیکاتورها با اعلان تلگرام و پوش بومی حتی وقتی برنامه کاملاً بسته است.

- 🌙 **تم تیره/روشن**: در تنظیمات ← «ظاهر برنامه»، بلافاصله روی کل برنامه اعمال و ذخیره می‌شود
- 💰 **قیمت تتر بزرگ‌تر و خواناتر** در کارت مجموع دارایی‌ها (مدیریت دارایی)
- 🗂 **ترتیب جدید سربرگ‌ها (راست→چپ)**: تنظیمات، مدیریت دارایی، ترید با AI، اندیکاتورها، ردیابی نهنگ‌ها، قبل از پامپ، شورت میم‌کوین، اسکنر دامپ‌وپامپ
- 🌐 **آدرس سرور پیش‌فرض داخل برنامه**: `https://pompay-production.up.railway.app` در فیلد تنظیمات خودکار پر می‌شود ولی قابل ویرایش برای دیپلوی شخصی است

- 📲 **نصب روی نسخه قبلی**: نسخه جدید بدون حذف برنامه قبلی نصب می‌شود (versionCode=4)

## اتصال اپ به سرور
- آدرس پیش‌فرض `https://pompay-production.up.railway.app` **از قبل داخل برنامه قرار داده شده** و در تنظیمات ← «سرور اسکنر» خودکار پر شده است.
- اگر نسخه شخصی خودتان را دیپلوی کردید، همان فیلد را با آدرس خودتان ویرایش کنید ← تست و ذخیره ← همگام‌سازی پیکربندی.

## ساختار
- `app/` — ۸ صفحه اکسپو (اسکنر، میم، قبل لیست، نهنگ، ترید AI، کیف پول، اندیکاتورها، تنظیمات)
- `utils/` — سرویس‌ها (تلگرام، بایننس، نوبیتکس، GainzAlgo، هوک، پوش، AI)
- `server/` — سرور اسکنر برای Railway (Root Directory = `server`)
- `functions/` — نسخه اصلی Cloudflare (مرجع تاریخی؛ در زیپ GitHub و دیپلوی Railway قرار نمی‌گیرد)

## دیپلوی سرور روی Railway
1. ریپو را به GitHub بدهید
2. در Railway: New Project → Deploy from GitHub repo
3. Settings → Root Directory = `server`
4. (اختیاری) متغیرها: `OPENAI_API_KEY`, `NOBITEX_API_PUBLIC_KEY`, `NOBITEX_API_PRIVATE_KEY`
5. دامنه عمومی Railway را کپی کنید (مثلاً `https://xxx.up.railway.app`)

## اتصال اپ به سرور (خودکار)
آدرس `pompay-production.up.railway.app` از قبل داخل برنامه است؛ فقط برای سرور شخصی، تنظیمات ← «سرور اسکنر» ← آدرس را ویرایش کنید ← تست و ذخیره ← همگام‌سازی پیکربندی (توکن ربات تلگرام + اندیکاتورها روی سرور ثبت می‌شوند).

## بیلد APK
- محلی: `npm install` سپس `npx expo prebuild -p android` سپس `cd android && ./gradlew assembleRelease`
- ابری: `npx eas build -p android --profile preview` (خروجی APK)

## اعلان با برنامه بسته
- کانال اصلی: ربات تلگرام — سرور هر ساعت/۴ ساعت/روزانه اسکن می‌کند و سیگنال‌های جدید را به تلگرام می‌فرستد (کاملاً مستقل از گوشی)
- کانال دوم: پوش بومی (Expo Push/FCM) — پس از ثبت در تنظیمات


## 🔁 بروزرسانی خودکار برنامه (نسخه 1.2.0 به بعد)
- ریپو شامل پوشه `apk/` است: `PampDumpCoins-latest.apk` + `version.json`
- برنامه هر ۳۰ دقیقه (و در هر باز شدن) `version.json` را چک می‌کند؛ اگر نسخه جدید باشد:
  - بنر «نسخه جدید منتشر شد» بالای صفحه با دکمه دانلود مستقیم APK نمایش داده می‌شود
  - در تنظیمات، نسخه نصب‌شده + دکمه «بروزرسانی» چشمک‌زن ظاهر می‌شود

### انتشار نسخه جدید (خلاصه)
1. APK جدید را با همین نام جایگزین `apk/PampDumpCoins-latest.apk` کنید
2. در `apk/version.json` مقدار `latestVersion` را زیاد کنید و در صورت تمایل `notes` را بنویسید
3. ✅ آدرس بررسی نسخه از قبل داخل برنامه قرار داده شده (`utils/appUpdate.ts` → `DEFAULT_UPDATE_URL` → ریپوی `ostad2fan/pompay`) — نیازی به تنظیم دستی نیست و بخش آدرس دانلود از تنظیمات حذف شده است
4. 📲 برای نصب روی نسخه قبلی بدون حذف: نام پکیج یکسان + keystore یکسان + versionCode بالاتر (جزئیات در `apk/README.md`)

### کلیدهای صرافی (به‌جای هاردکد، در env سرور)
در Railway → Variables:
- `NOBITEX_API_PUBLIC_KEY` / `NOBITEX_API_PRIVATE_KEY` (نوبیتکس)
- `ARZINJA_API_PUBLIC_KEY` / `ARZINJA_API_PRIVATE_KEY` (ارزینجا)
- `OPENAI_API_KEY` (اختیاری، برای AI)

### نکته ساخت
پوشه `android/` خروجی `npx expo prebuild -p android` است و برای سبک‌ماندن ریپو در این زیپ قرار نگرفته؛ برای بیلد محلی فقط دستور prebuild بالا را اجرا کنید.
