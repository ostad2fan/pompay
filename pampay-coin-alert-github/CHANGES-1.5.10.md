## ۱) خروجی PDF بک‌تست — جدول کامل با همه جزئیات (امروز + ۷ روز)

- در بازه‌ی «امروز» و «۷ روز»: جدول ریزِ «همه‌ی» معاملات همان بازه با **تمام ستون‌ها** درج می‌شود — بدون حالت فشرده، هر تعداد معامله که باشد:
  **ارز، جهت/لوریج، استراتژی، اندیکاتور/منبع، نقطه ورود، استاپ، تیک‌پرافیت، قیمت خروج (ستون جدید)، حجم مارجین، ساعت باز شد، ساعت بسته شد، نوع بسته شدن، سود/زیان.**
- «قیمت خروج» = قیمت لحظه‌ی بسته شدن معامله؛ توضیح آن (رابطه‌ی ورود/خروج با سود دلاری) به پانویس PDF اضافه شد. اگر قیمت خروج ثبت نشده باشد «—» نمایش داده می‌شود.
- حالت فشرده (از ۲۵۰ معامله به بالا با ستون‌های کمتر) **کاملاً حذف شد** — حتی ۲۰۰۰ معامله با همه‌ی ستون‌ها می‌آید.
- سرعت حفظ شد: کلاس‌های CSS به‌جای استایل درون‌خطی، بدون ایموجی هر ردیف، ساخت رشته با join یک‌باره — حتی ۲۰۰۰ معامله در چند ثانیه.
- بازه‌های «۳۰ روز» و «همه»: طبق درخواست قبلی کاربر فقط خلاصه‌ی آمار + یادداشت راهنما (برای ریز معاملات، بازه‌ی ۷ روز یا امروز را انتخاب کنید).

## ۲) رفع خطای 404 دکمه دانلود آپدیت

- ریشه: لینک دانلود به فایل APK نسخه‌دار (مثلاً `PampDumpCoins-v1.5.10.apk`) روی گیتهاب اشاره می‌کند؛ اگر آن فایل آپلود نشده باشد، مرورگر صفحه‌ی 404 نشان می‌داد و زنجیره‌ی fallback هرگز اجرا نمی‌شد (openURL فقط وقتی خطا می‌دهد که هیچ مرورگری نباشد، نه وقتی فایل نیست).
- رفع: قبل از باز کردن مرورگر، هر لینک با یک درخواست ۲ بایتی بررسی می‌شود و اولین لینکی که واقعاً وجود دارد باز می‌شود (نسخه‌دار CDN → نسخه‌دار GitHub → فایل latest) — اگر APK نسخه‌دار آپلود نشده باشد، خودکار فایل latest دانلود می‌شود. سقف بررسی: ۴ ثانیه برای هر لینک، ۲۰ ثانیه جمعاً — دکمه هرگز معلق نمی‌ماند.

## ۳) سرور Railway بیدار می‌ماند (کد سرور — redeploy لازم)

- سرویس‌های Railway بعد از بی‌حرکتی می‌خوابند (spin-down) → همه‌ی پایش ۲۴/۷ (اسکنر، اندیکاتورها، نهنگ‌ها، بک‌تست) با برنامه‌ی بسته متوقف می‌شد.
- حالا سرور هر ۴ دقیقه آدرس `/ping` عمومی خودش را صدا می‌زند و بیدار می‌ماند (فقط وقتی `RAILWAY_PUBLIC_DOMAIN` تنظیم شده باشد — روی Railway خودکار است).
