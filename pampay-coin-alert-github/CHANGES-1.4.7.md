# تغییرات نسخه ۱.۴.۷ — گیت IP ایران + رفع ریشه‌ای ارزینجا/نوبیتکس/بیت‌پرپ + PnL

این نسخه روی همان کد پایدار ۱.۴.۶ ساخته شده و ۱۴ خواسته گزارش‌شده را پیاده/رفع می‌کند.

## ۱) گیت IP هنگام باز کردن برنامه (صفحه تمام‌صفحه)

- به‌محض باز شدن برنامه، IP عمومی و کشور فعلی گوشی تشخیص و نمایش داده می‌شود («IP فعلی شما: X — کشور: Y»).
- **IP ایران** → پیام «برای استفاده از برنامه فیلترشکن را روشن کنید» + دکمه «تأیید و خروج از برنامه» (برنامه بسته می‌شود؛ دکمه بازگشت اندروید هم خروج است) + دکمه «فیلترشکن را وصل کردم — بررسی مجدد».
- **IP غیر ایران (فیلتر روشن)** → پیام سبز «اتصال از کشور X برقرار است» و ورود خودکار.
- هر بار برنامه از پس‌زمینه به پیش‌زمینه بیاید، دوباره بررسی می‌شود (خاموش کردن فیلترشکن وسط کار هم گرفته می‌شود).
- اگر سرویس‌های تشخیص IP در دسترس نباشند (وضعیت unknown) برنامه قفل نمی‌شود — گیت داخل بخش مدیریت دارایی همچنان محافظت می‌کند.

## ۲) گیت IP ایران در مدیریت دارایی (سخت — Hard Gate)

- اگر فیلترشکن خاموش باشد و IP ایران تشخیص داده شود:
  - **هیچ درخواستی** — نه موجودی، نه PnL، نه قیمت — به صرافی‌های خارجی (بایننس، بای‌بیت، OKX، بیت‌پرپ، مکسی، هوبی و…) ارسال نمی‌شود؛ کوئری‌ها کامل غیرفعال می‌شوند.
  - داخل کارت هر صرافی خارجی، کادر نارنجی «فیلترشکن را وصل کنید» با توضیح امنیتی نمایش داده می‌شود.
  - فایل استخراج‌شده (snapshot) قبلی محلی قابل دیدن می‌ماند — بدون ارسال کلیدها به بیرون.
- به‌محض روشن شدن فیلترشکن (بررسی هر ۶۰ ثانیه یا دکمه «بررسی مجدد»)، موجودی و PnL همه صرافی‌های خارجی **خودکار** تازه می‌شوند.
- صرافی‌های ایرانی (ارزینجا، نوبیتکس، ایرانیکارت) با IP ایران بدون محدودیت کار می‌کنند.

## ۳) ارزینجا — رفع ریشه‌ای (مهم‌ترین باگ این نسخه)

**مشکل:** کلید فقط‌خواندنی وارد می‌شد ولی موجودی نمی‌آمد و خطای گمراه‌کننده می‌آمد.

**علت واقعی:** برنامه به `api.arzinja.ir` وصل می‌شد و مسیرها/احراز هویت را به سبک نوبیتکس می‌فرستاد — در حالی که آن دامنه **اصلاً دیگر وجود ندارد** (NXDOMAIN). یعنی هیچ‌وقت حتی یک بایت به ارزینجا نرسیده بود و ربطی به کلید شما نداشت.

**رفع:** یکپارچه‌سازی کامل با **API واقعی v2 ارزینجا** (مستندات رسمی arzinja.ir/api-docs):
- آدرس پایه: `https://api-v2.arzinja.app/api` (+ فالبک `.ir`)
- موجودی: `GET /v1/services/wallet/balances` با امضای HMAC-SHA256 و هدرهای `X-ARZ-API-KEY / X-ARZ-SIGN / X-ARZ-TIMESTAMP / X-ARZ-RECV-WINDOW` — دقیقاً طبق مستند رسمی (با کلید ساختگی تست شد: مسیر و امضا پذیرفته می‌شود).
- قیمت‌گذاری هر ارز با فیلد `estimated_usdt` خود ارزینجا؛ تومان (IRT) با نرخ لحظه‌ای تتر.
- خطاهای دقیق فارسی: کلید نامعتبر / امضا رد شد / محدودیت دسترسی / محدودیت نرخ.

## ۴) نوبیتکس — دامنه API عوض شده بود

دامنه قدیمی `api.nobitex.ir` هم NXDOMAIN شده؛ نوبیتکس به `apiv2.nobitex.ir` منتقل شده است. هم مسیر قیمت تتر و هم مسیر موجودی نوبیتکس (و سرور Railway برای `/nobitex/usdt-toman`) اصلاح شد. تأیید زنده: `market/stats` → 200.

## ۵) بیت‌پرپ — سه رفع

1. **خطای شبکه ≠ نشست منقضی:** قبلاً هر خطای شبکه/تایم‌اوت هنگام تمدید توکن، به‌اشتباه «نشست BitPerp منقضی شده» نشان داده می‌شد. حالا مثل خود سایت بیت‌پرپ بین «رد شدن واقعی نشست» و «خطای گذرا» فرق گذاشته می‌شود.
2. **خطاهای داخل پاسخ ۲۰۰:** اگر صرافی با `code!=0` خطا برگرداند، پیام خودش به فارسی نمایش داده می‌شود (قبلاً موجودی خالی نشان داده می‌شد).
3. **باگ چرخش توکن (مهم):** بعد از تمدید موفق، توکن جدید فقط در حافظه ذخیره می‌شد و نسخه درون‌حافظه برنامه هنوز توکن یک‌بارمصرفِ قبلی را داشت → دفعه بعد «نشست منقضی» اشتباهی. حالا توکن‌های چرخیده هم‌زمان در کوئری و AsyncStorage جایگزین می‌شوند.

## ۶) PnL دوره‌ای — بالای لیست ارزها

بخش «سود/زیان (PnL) دوره‌ای» از انتهای کارت به **ابتدای لیست ارزها** (بعد از چیپ‌های بخش‌ها) منتقل شد تا بدون اسکرول دیده شود. انتخاب بازه ۳۰/۹۰/۱۸۰/۳۶۰ روزه همان‌جا؛ جزئیات (محقق‌شده/فاندینگ/کارمزد/باز/مجموع) زیرش.

## ۷) PnL دوره‌ای کل دارایی‌ها (بخش جدید)

در کارت «مجموع دارایی‌ها» بخش جدید «سود/زیان دوره‌ای کل دارایی‌ها (مجموع صرافی‌ها)» اضافه شد: بازه ۳۰/۹۰/۱۸۰/۳۶۰ روز + مجموعِ PnL همه صرافی‌های دارای API دوره‌ای (بایننس/بای‌بیت/OKX/بیت‌پرپ) با تفکیک ریز اقلام. تحت گیت ایران، صرافی‌های خارجی‌اش هم مسدود می‌شود.

## ۸) خطاهای سرور — تشخیص دقیق‌تر

«همگام‌سازی پیکربندی» حالا مثل «تست اتصال» علت دقیق را می‌گوید: ۵۰۲ Railway (سرور خاموش — Redeploy کنید) / اینترنت خودتان قطع / توکن و چت‌آیدی تنظیم نشده. (تست اتصال، تست تلگرام و ثبت نوتیف از ۱.۴.۶ همین رفتار را داشتند.)

## ۹) اسلیپ Railway و وضعیت فعلی سرور

- سرور `pompay-production.up.railway.app` در زمان ساخت این نسخه **خاموش/کرش است** (پاسخ 502 از پروکسی Railway) — ریشه‌ی ۴ خطای گزارش‌شده شما (ذخیره آدرس / همگام‌سازی / تست تلگرام / ثبت نوتیف) همین است.
- راه‌حل کامل + جلوگیری از خوابیدن (keep-alive رایگان با cron-job.org هر ۵ دقیقه): **`docs/RAILWAY-KEEPALIVE.md`** — ۲ دقیقه کار دارد.

## ۱۰) فایل keystore در گیت‌هاب

`apk/keystore/pampay-release-key.jks` برای امضای نصب-روی-نسخه‌های-قبلی **لازم است** و در ریپو می‌ماند؛ اما چون ریپو `ostad2fan/pompay` عمومی است، هر کسی می‌تواند آن را دانلود کند و APK هم‌امضا با همان نام پکیج بسازد. توصیه امنیتی: ریپو را **Private** کنید یا keystore را از ریپو حذف و فقط نسخه‌های شخصی خودتان را نگه دارید (در این صورت نسخه‌های آینده باید مثل قبل با همین فایل امضا شوند تا روی برنامه فعلی نصب شوند). تصمیم با شماست — تغییری داده نشد.
