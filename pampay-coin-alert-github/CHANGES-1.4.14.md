# تغییرات نسخه ۱.۴.۱۴ (PampDumpCoins)

## ۱) سه تب بالای صفحه «مدیریت دارایی»
صفحه مدیریت دارایی که قبلاً یک لیست طولانی بود، حالا **سه تب مجزا در بالای صفحه** دارد:

| تب | محتوا |
|---|---|
| **ارز دیجیتال** | کارت مجموع دارایی‌ها + کارت هر صرافی + افزودن صرافی جدید |
| **دارایی ریالی و فلزات** | قیمت‌های لحظه‌ای تومانی + ورودی دارایی‌های شما + مجموع کل |
| **پیش‌بینی قیمت طلا** | قرارداد آتی شمش طلای خام IME + فرمول تبدیل عیار |

- تبِ آخر انتخاب‌شده به‌خاطر سپرده می‌شود و دفعه بعد همان تب باز می‌شود.

## ۲) رفع باگ بیت‌پرپ (BitPerp) — دارایی‌های جدید نمایش داده نمی‌شد
**ریشه مشکل:** صرافی بیت‌پرپ ساختار کیف پول خود را تغییر داده و حساب را به چهار زیرحساب
تقسیم کرده: **فاندینگ / اسپات / پرپ (فیوچرز) / کپی‌تریدینگ**. اندپوینت‌های قدیمی
(`/api/balance` و `/api/fund-balance`) الان داده کهنه و ناقص برمی‌گردانند — برای همین
ارزهای جدید شما (مثلاً آن‌هایی که در کیف اسپات یا زیرحساب جدید بودند) دیده نمی‌شدند و
فقط همان ارزهای قدیمی زیر ۵ سنت می‌ماندند.

**راه‌حل (کشف‌شده از باندل زنده اپ رسمی bitperp.com):**
- اندپوینت‌های جدید خوانده می‌شوند:
  - `GET /api/spot/fund-balance` → دارایی‌های حساب فاندینگ
  - `GET /api/spot/balance` → دارایی‌های حساب اسپات
  - `GET /api/v2/perp-balances` → دارایی‌های حساب پرپ
  - `GET /api/wallet/overview` → موجودی حساب کپی‌تریدینگ
- دارایی‌ها با برچسب زیرحساب واقعی خودشان نمایش داده می‌شوند (اسپات / فاندینگ / فیوچرز / کپی‌ترید).
- اگر اندپوینت‌های جدید در دسترس نبود، مسیر قدیمی همچنان کار می‌کند (سازگاری کامل).

## ۳) رفع باگ قیمت فلزات (به‌خصوص با فیلترشکن روشن)
دو مشکل ریشه‌ای پیدا و رفع شد:
- **خطای واحد ریال/تومان:** قیمت‌های TGJU به ریال است؛ تبدیل قبلی در سطح قیمت فعلی
  اعمال نمی‌شد → قیمت‌ها ۱۰ برابر بزرگ یا کلاً «در دسترس نیست» بود.
- **زنجیره ۳ لایه‌ای دریافت:**
  1. سه آینه مستقیم TGJU (`call1` / `call2` / `call`)
  2. مسیر پروکسی (`allorigins`) — برای وقتی IP خروجی فیلترشکن توسط Cloudflare چالش
     می‌شود؛ پروکسی با IP خودش فایل را می‌گیرد و همان JSON را برمی‌گرداند
  3. کش تا ۲۴ ساعت با مهر زمانی «آخرین دریافت» — شبکه‌های مشکل‌دار دیگر صفحه را خالی نمی‌کنند

## ۴) سود/زیان (PnL) برای دارایی ریالی و فلزات
- کارت جدید زیر «مجموع کل»: تغییر ارزش دارایی‌ها در بازه‌های **۷ / ۳۰ / ۹۰ / ۱۸۰ روز**
- محاسبه بر اساس تاریخچه قیمت پایان روز TGJU (گرم طلا ۱۸/۲۴، نقره ۹۹۹/۹۲۵، سکه‌ها)
- نمایش جداگانه سود/زیان هر کلاس + درصد کل
- توجه: این «تغییر قیمت بازار» است، نه سود واقعی شما نسبت به قیمت خریدتان.

## ۵) تب «پیش‌بینی قیمت طلا» (IME — بازار آتی بورس کالا)
دقیقاً طبق نمونه تاییدشده:
- **کارت قیمت لحظه‌ای:** طلای ۱۸ عیار، ۲۴ عیار و معادل خام ۹۹۵ (زنده از TGJU)
- **کارت آتی شمش طلای خام IME:** آخرین سررسید فعال، قیمت معامله (ریال/گرم)، فرمول
  `۳۸,۴۶۰,۰۰۰ × (۷۵۰ ÷ ۹۹۵)` و نتیجه بزرگ طلایی + اختلاف درصدی با قیمت امروز
- **جدول قراردادهای فعال:** سررسید / قیمت آتی / پیش‌بینی ۱۸ عیار / اختلاف
- **ورود دستی:** چون IME فقط با IP ایران پاسخ می‌دهد، دکمه مداد ↗ قیمت و سررسید را
  دستی وارد کنید؛ محاسبه و ذخیره انجام می‌شود (پاک‌کردن = برگشت به حالت خودکار)
