## آزمایش پوش

1. برنامه را نصب و باز کنید → مجوز نوتیفیکیشن را **Allow** کنید
2. تنظیمات ← «تست نمایش نوتیفیکیشن» ← باید همان لحظه اعلان ببینید
3. «ثبت نوتیفیکیشن گوشی» را بزنید → توکن دستگاه روی سرور ثبت می‌شود
4. از این به بعد هر سیگنالی که سرور تشخیص دهد، هم تلگرام و هم نوتیف گوشی می‌رسد

## نکته‌های مهم اندروید

- برای تحویل مطمئن با برنامه بسته: تنظیمات گوشی → Battery → اپ → **Unrestricted / بدون محدودیت**
- روی گوشی‌های شیائومی/اوپو: از قفل شدن اپ جلوگیری کنید (Autostart + Battery)
- FCM گوگل در ایران معمولاً کار می‌کند ولی روی برخی شبکه‌ها ممکن است کند باشد؛ **مسیر تلگرام به‌عنوان پشتیبان همیشه فعال می‌ماند**
- اگر روزی خواستید پروژه فایربیس را عوض کنید: فایل `google-services.json` جدید را جایگزین کنید (ریشه پروژه و `android/app/`) و دوباره بیلد بگیرید

## اگر ارسال پوش از سرور خطا داد (اختیاری)

سرویس پوش اکسپو برای ارسال با حجم بالا به توکن اکانت نیاز دارد: در
[expo.dev/settings/access-tokens](https://expo.dev/settings/access-tokens) یک Access Token بسازید
و روی Railway در Variables اضافه کنید: `EXPO_ACCESS_TOKEN`

## نحوه کار در کد

| بخش | فایل |
|---|---|
| گرفتن توکن و ارسال به سرور | `contexts/AppContext.tsx` → `registerPushOnServer()` (خودکار در اجرا) |
| دکمه ثبت و تست | `app/(tabs)/settings/index.tsx` |
| ارسال اعلان سرور → گوشی | `server/src/push.ts` → `sendPushToAll()` |
| ثبت توکن روی سرور | `POST /push/register` |
| مشاهده تعداد دستگاه‌ها | `GET /push/status` |
