- **تلگرام**: بعد از وارد کردن توکن ربات در تنظیمات اپ، بدون هیچ کار اضافه‌ای کار می‌کند و **مسیر اصلی اعلان با برنامه بسته** است.
- **پوش نوتیف خود اپ**: کدش کامل است؛ فقط باید فایل فایربیس به بیلد اضافه شود.

## قدم نهایی: افزودن google-services.json (۵ دقیقه)

> ⚠️ **نام پکیج اندروید** که در فایربیس ثبت می‌کنید باید دقیقاً این باشد:
> ```
> com.trademaster.pampaycoin
> ```

1. به [console.firebase.google.com](https://console.firebase.google.com) بروید → پروژه خودتان → آیکون **Android** 🤖
2. Package name را `com.trademaster.pampaycoin` بگذارید → **Register app**
3. **Download google-services.json** را بزنید
4. فایل را اینجا قرار دهید:
   - **پکیج کامل محلی**: `android/app/google-services.json` (کنار build.gradle)
   - **پروژه سبک گیت‌هاب**: اول فایل را در ریشه پروژه بگذارید، در `app.json` بخش `"android"` این را اضافه کنید:
     ```json
     "googleServicesFile": "./google-services.json"
     ```
     سپس `npx expo prebuild -p android --no-install` اجرا کنید تا خودش کپی شود.
5. دوباره APK بسازید:
   ```bash
   cd android && ./gradlew assembleRelease
   ```

> 🧰 نیازی به تغییر gradle نیست — از نسخه ۱.۴.۱ پلاگین `google-services` به‌صورت **خودکار** فقط در صورتی فعال می‌شود که فایل `google-services.json` کنار build.gradle وجود داشته باشد.

## اگر بعد از افزودن فایل، پوش هنوز نرسید

سرویس پوش اکسپو برای تحویل روی اندروید، اعتبارنامه FCM پروژه شما را می‌خواهد:

```bash
npm i -g eas-cli
eas login            # با اکانت اکسپویی که projectId از آن است
eas credentials -p android   # فایل google-services.json / کلید FCM را آپلود کنید
```

## قدم اختیاری: محدودیت ارسال بالاتر

اگر حجم اعلان زیاد شد: در [expo.dev/settings/access-tokens](https://expo.dev/settings/access-tokens) یک Access Token بسازید و روی Railway در Variables اضافه کنید: `EXPO_ACCESS_TOKEN`

## نحوه کار در کد

| بخش | فایل |
|---|---|
| گرفتن توکن و ارسال به سرور | `contexts/AppContext.tsx` → `registerPushOnServer()` (خودکار در اجرای برنامه) |
| دکمه ثبت و تست دستی | `app/(tabs)/settings/index.tsx` → «ثبت نوتیفیکیشن گوشی» + «تست نمایش نوتیفیکیشن» |
| ارسال اعلان سرور → گوشی | `server/src/push.ts` → `sendPushToAll()` |
| ثبت توکن روی سرور | `POST /push/register` |
| مشاهده تعداد دستگاه‌ها | `GET /push/status` |

## نکته‌های مهم اندروید

- بعد از نصب، اولین اجرا باید permission نوتیفیکیشن را **Allow** کنید
- برای تحویل مطمئن با برنامه بسته: تنظیمات گوشی → Battery → اپ → **Unrestricted / بدون محدودیت**
- روی گوشی‌های شیائومی/اوپو: از قفل شدن اپ جلوگیری کنید (Autostart + Battery)
- FCM گوگل در ایران معمولاً کار می‌کند ولی روی برخی شبکه‌ها ممکن است کند باشد؛ به همین خاطر **مسیر تلگرام به‌عنوان پشتیبان همیشه فعال می‌ماند**
