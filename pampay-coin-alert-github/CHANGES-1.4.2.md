## تغییرات

### ۱) صرافی BitPerp (بیت‌پرپ)
- `types/crypto.ts`: شناسه `bitperp` به نوع `ExchangeId` اضافه شد.
- `constants/exchanges.ts`: صرافی **بیت‌پرپ (BitPerp)** با آدرس `https://bitperp.com` به لیست صرافی‌ها اضافه شد — حالا در بخش «مدیریت دارایی» قابل انتخاب است و کلید API آن را می‌توانید وارد کنید.
- `app/(tabs)/wallet/index.tsx`: اتصال اختصاصی BitPerp:
  - تابع `fetchBitperpBalance()` — دریافت موجودی از مسیر `/api/balance` صرافی.
  - چون BitPerp مستندات عمومی API ندارد، احراز هویت به‌صورت هوشمند با چند طرح هدر امتحان می‌شود (`X-API-KEY` → `Bearer` → `X-MBX-APIKEY`) و پاسخ با parser انعطاف‌پذیر خوانده می‌شود.
  - دارایی‌های بدون ارزش دلاری با قیمت لحظه‌ای بایننس ارزش‌گذاری می‌شوند (مثل بای‌بیت و OKX).
  - در صورت خطای اتصال، پیام فارسی واضح نمایش داده می‌شود و کلید ذخیره می‌ماند.
